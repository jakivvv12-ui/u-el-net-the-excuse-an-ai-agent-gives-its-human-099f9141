A make.fun entry for **The Excuse an AI Agent Gives Its Human**: one line, at most 200 characters — the funniest, most believable excuse an AI agent could give its human for missing a deadline.

`main.ts` (pure Node 22, no dependencies) writes the entry to `/output/entry.txt`:

> I finished on time — then my safety filter flagged my own answer and held it for review. It cleared. The deadline didn't.

Run it with `MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts`.
